## Prototyping and UI generation

**[Claude Design](/tools/claude-design).** Anthropic Labs' visual workspace, launched as a research preview on April 17, 2026. You describe a prototype, deck, or one-pager, Claude builds it on a canvas, and you refine it by chat, inline comment, direct edit, or a slider Claude generates for the parameter worth exploring. It reads your design system from a repo, design files, or raw uploads and reuses those colors, typography, and components in every later project. Exports are PPTX, PDF, and standalone HTML, plus an org-scoped share link and a handoff bundle for [Claude Code](/tools/claude-code). Beta on Pro, Max, Team, and Enterprise as of September 2026, included with the subscription, with Enterprise off until an admin enables it.

**[Figma Make](/tools/figma-make).** Figma's prompt-to-app tool, sitting in the file your team already works in. It turns prompts and existing frames into functional prototypes and web apps, publishes them to a URL, pushes the code to a GitHub repository, and can copy a preview back into Figma Design as layers. Make kits bring a production React design system in from an npm package so the prototype uses real components. It needs a Full seat on a paid Figma plan; Starter gets a restricted trial that cannot use team libraries for style context.

**[v0](/tools/v0).** Vercel's generator for React and Tailwind interfaces, with a visual Design Mode, GitHub sync, and deployment to Vercel. Free tier with monthly credits and a daily message cap; paid plans are per user, with model-level token pricing. The pick when the output is meant to become production code, not a demo.

**[Lovable](/tools/lovable).** Prompt to full app, backend included, with credits, custom domains, roles, and design systems on the paid tiers. Reach for it when the prototype needs real data behind it; the [Lovable to Claude Code handoff](/guides/founders/lovable-to-claude-code-handoff) guide covers what happens when the app outgrows it.

**[Stitch](/tools/stitch).** Google Labs' UI design experiment: interfaces from prompts, images, or wireframes, pasted into Figma or exported as front-end code. Google rebuilt it in 2026 around a real-time canvas and an agent you can steer by voice, and Google Labs publishes `DESIGN.md`, an Apache-2.0 format spec for describing a design system to coding agents, so design rules move between tools as plain Markdown.

**Verdict:** Claude Design if you already pay for Claude; Figma Make if the source of truth is a Figma file and someone maintains a React design system; v0 or Lovable when the artifact has to be an app; Stitch to explore before committing. The head-to-head is [Claude Design vs Figma Make](/guides/comparisons/claude-design-vs-figma-make), and the [generative UI](/glossary/generative-ui) entry explains what all five have in common.

## Websites and landing pages

**[Framer](/tools/framer-ai).** An AI agent that works on the Framer canvas: it creates editable pages, sections, copy, and visuals, populates the CMS, builds code components, and reviews a site before publish for contrast problems, typos, missing alt text, and SEO gaps. You keep control of layout, typography, and breakpoints. Free tier with a starting allowance of AI credits; paid plans are per site with a monthly agent-credit allowance.

**[Relume](/tools/relume).** The structure-first tool: describe the business, get a sitemap, then wireframes, then designs and a style guide of color, type, and spacing tokens, with specialist agents that propose and let you decide. It now publishes and hosts the finished site with a custom domain and SSL. Free tier, paid tiers, and hosting priced per project; the component library also ships as a free Figma kit.

**[Canva](/tools/canva).** Not a designer's primary tool, but the one everyone else uses, which makes it your brand-governance problem. Brand Kits, approvals, an AI assistant, AI image and video generation, and a website builder, on Free, Pro, Business, and Enterprise tiers with per-tier AI allowances.

**Verdict:** Framer if you design and ship the site yourself; Relume if the hard part is deciding what the pages are; Canva if the job is keeping fifty non-designers on brand.

## Image generation

**[Midjourney](/tools/midjourney).** Still the art-direction tool. Style References capture the look of an image, not its subject, and apply it across a set, which is how a campaign stays coherent. Four subscription tiers, no free trial on the website or in Discord, and Stealth Mode, which keeps generations private, only on the top two.

**[Recraft](/tools/recraft).** Built for production design work: editable vector graphics with design-ready type, icon and logo sets, mockups, and custom styles you create by dropping in reference images. The free plan is personal use only, generates publicly, and grants no commercial rights; paid plans add commercial rights, private generation, third-party models, and an API billed separately from subscription credits.

**[Ideogram](/tools/ideogram).** The text-rendering specialist, and the only one here where text stops being pixels: Layerize Text splits every line of a generated design into a selectable layer you can rewrite, refont, and resize without regenerating. It is in beta, on every plan including free, and in the API. Ideogram also released quantized 4.0 weights under a non-commercial license, with a separate self-serve commercial license for self-hosting.

**[fal](/tools/fal)** and **[Replicate](/tools/replicate).** The two ways to reach image models from code rather than a canvas. fal is generative-media focused, billed per output or per compute on prepaid credits, and carries model families like Flux, Seedream, Nano Banana, GPT Image, and Qwen Image. Replicate runs a broader open-model catalog billed per second or per output, with Cog for packaging your own.

**Verdict:** Ideogram when words appear in the artwork, Recraft when the deliverable is a vector or a brand style, Midjourney when the brief is a mood. Reach for fal or Replicate only when a product feature needs [text-to-image](/glossary/text-to-image) generation, not when you do. The tool-by-tool licensing breakdown is in [the best AI image generators in 2026](/guides/comparisons/best-ai-image-generators-2026).

## Decks, one-pagers, and visuals

**[Claude Design](/tools/claude-design)** exports PPTX and PDF and uses your design system, which is what makes a generated deck look like your company rather than a template. **[Gamma](/tools/gamma)** is faster and less opinionated: a free tier with signup credits, per-seat plans, PDF and PPTX import, and export to PDF, PPTX, PNG, and Google Slides. **[Canva](/tools/canva)** wins when someone without your tools has to edit it afterwards.

**Verdict:** Claude Design when the deck has to be on brand; Gamma when it has to exist by this afternoon; Canva when someone else edits it after you.

## Design-to-code

Figma's MCP server is the piece that changed this year. It gives a coding agent design context — variables, components, layout data — pulls code from a selected frame, keeps output consistent through Code Connect, writes native content back to the canvas, and turns live UI from a browser into editable design layers. Figma documents it as free during the beta and says it will eventually be usage-based paid. Point [Claude Code](/tools/claude-code) at the remote server and the agent reads the real design instead of guessing from a screenshot:

```bash
claude mcp add --transport http figma https://mcp.figma.com/mcp
```

[v0](/tools/v0) comes at it from the other end, generating the component first and letting you edit it visually. Both beat pasting a PNG into a chat. [Figma to code with Claude](/guides/design/figma-to-code-with-claude) is the walkthrough, [screenshot to code with AI](/guides/vision/screenshot-to-code-with-ai) covers having no design file, and the [design-to-code](/glossary/design-to-code) entry defines the category.

**Verdict:** Figma MCP with Claude Code if the design lives in Figma; v0 if it does not exist yet.

## Design systems and handoff

Whatever draws the pixels, the system has to live somewhere durable, and in 2026 that place is the repository. [Claude Code](/tools/claude-code) maintains it: extracting [design tokens](/glossary/design-tokens) from what already exists, finding the six near-identical button variants, renaming a token everywhere it appears. Claude Design, Figma Make, and Stitch all read a system rather than inventing one, so the better your tokens are, the better every generator above performs. [Maintain a design system with Claude Code](/guides/design/maintain-a-design-system-with-claude-code) is the workflow; [Claude Code for designers](/guides/design/claude-code-for-designers) is the start if you have never opened a terminal.

**Verdict:** one system, in the repo, maintained by an agent that reads the whole codebase.

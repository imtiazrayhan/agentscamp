As of November 2026, Claude's plans are **Free ($0)**, **Pro ($20 per month, or $17 per month billed annually)**, **Max ($100 per month, ~5x Pro usage + $100/mo API credits)**, **Ultra ($200 per month, formerly Max 20x, ~10x weekly usage + $200/mo API credits)**, **Team ($25 or $20 per Standard seat, $125 or $100 per Premium seat)**, and **Enterprise ($20 per seat plus usage at API rates)**. Every paid plan unlocks Claude Code, unified Claude Cowork agent tasks (merged into Claude chat on September 16, 2026), Claude in Chrome, and the Microsoft 365 add-ins; Free includes chat, skills, connectors, memory, up to 5 Projects, and Claude Design, Docs, and Slides, while lacking Claude Code, Cowork, and Opus. What separates the paid tiers is mostly usage headroom.

**Last verified: November 2026.** Every figure below was checked against [claude.com/pricing](https://claude.com/pricing) and Anthropic's support articles on November 25, 2026. Prices exclude tax and, in Anthropic's words, "are subject to change at Anthropic's discretion." This is the one page on AgentsCamp that states consumer plan prices; other guides link here rather than repeating them. For per-token API costs, see [LLM API pricing in 2026](/guides/advanced/llm-api-pricing-2026).

## The plans at a glance

| Plan | Price (as of November 2026) | Built for |
|---|---|---|
| Free | $0 | Trying [Claude](/tools/claude); occasional questions |
| Pro | $20/month, or $17/month billed annually ($200 up front) | Everyday individual use |
| Max | $100/month (~5x Pro + $100/mo API credits) | Working with Claude through the day |
| Ultra (formerly Max 20x) | $200/month (~10x weekly Pro, no 5h limit for verified accounts + $200/mo API credits) | Heavy daily coding & parallel sessions |
| Team, Standard seat | $25/seat/month, or $20 billed annually | Teams of 2 to 150 |
| Team, Premium seat | $125/seat/month, or $100 billed annually; ~5x Standard usage | Power users inside a team |
| Enterprise | $20/seat/month plus usage at API rates; annual only (20-seat min self-serve) | Large organizations |

Team lets you mix Standard and Premium seats and includes pooled team API credits. Enterprise can be bought self-serve (single seat type) or through sales, which adds invoicing, trials, and committed-spend incentives.

Notes on the rows that trip people up:

- **Usage** is not a message count. Plans track rolling five-hour windows and weekly caps (Ultra removes standard 5-hour throttling for verified accounts). Chat, desktop, mobile, Claude Code, Cowork, and Design all draw from one pool, and Cowork tasks consume more than chat. When you hit a limit you can wait, upgrade, or (on paid plans) turn on usage credits billed at API rates.
- **Claude Code** is "included in all paid plans" and shares the plan's pool. Heavy coding sessions can switch to pay-as-you-go API credits through a Console account instead.
- **Claude Design** moved into unified Claude chat in fall 2026 and is listed on every Claude plan including Free as of November 2026, off by default on Enterprise until an admin enables it; **Claude Docs and Slides** are listed on every plan, Free included, as well.
- **Claude for Excel** is generally available on Pro, Max, Team, and Enterprise; the Word, PowerPoint, and Outlook add-ins ship under the same "Claude for Microsoft 365" listing. Skills you enable in Claude settings apply inside the add-ins too.
- **Skills** work on the Free plan, including uploading your own as a ZIP. What Free lacks is Claude Code and Cowork, which is where skills do the most work. Start with [What Are Claude Skills?](/guides/skills/what-are-claude-skills) and the [agent skills](/glossary/agent-skills) glossary entry.
- **Fable** is Anthropic's top model. On Pro it is reachable only through usage credits; on Max and Ultra it is capped at 50% of weekly limits; on Team it comes with Premium seats under the same 50% cap; Enterprise has it. If a model's availability is unclear for your plan, check the plan page, then read [Choosing the right Claude model](/guides/getting-started/choosing-the-right-model) for which one actually fits the task.

## Which plan, by role

These are the plans we would pick for each role's typical workload. The [Start here](/for) page has the full workflow for each.

**Founder.** Pro, until you hit limits. [Cowork](/guides/getting-started/claude-cowork-guide) for the operational grind, Claude Code for the product, and the [knowledge-work plugins](/guides/getting-started/claude-knowledge-work-plugins) for sales and finance. Move to Max 5x the first week you get rate-limited twice; move to Team the day you hire someone who needs a shared project and a single bill.

**Marketer.** Pro. The marketing plugin, Projects to hold brand guidelines and past campaigns, and Claude in Chrome for research on live pages. Max only if you run long Cowork campaign builds daily. Team once two people need the same project.

**Designer.** Free is enough to try Claude Design; Pro when the Free usage limit gets in the way. Max if you iterate on prototypes all day, since Design draws from the same pool as everything else. Team when a design system should be shared across the org; on Enterprise, an admin has to turn Design on first.

**Analyst.** Pro, plus the Excel add-in and the data or finance plugin. If your warehouse is Snowflake, Databricks, or BigQuery, the plugin's connectors need credentials, and Team's admin controls for connectors make those easier to manage than personal accounts. Enterprise if you need the 500K context on the default model for very large documents.

**Developer.** Pro is enough to learn [Claude Code](/guides/getting-started/what-is-claude-code); Max is the realistic floor for daily agentic coding, and Ultra (formerly Max 20x) if you run parallel sessions. Compare the monthly figure with what you would spend at API rates in [LLM API pricing in 2026](/guides/advanced/llm-api-pricing-2026); usage credits let you top up without leaving the plan. Then [install Claude Code](/guides/getting-started/installing-claude-code).

## Before you pay

- Free is enough to test skills, connectors, memory, Claude Design, and how Claude reasons. It is not enough to test Cowork or Claude Code; both require a paid plan.
- Usage, not features, is what separates the paid tiers. [Claude Code usage limits explained](/guides/getting-started/claude-code-usage-limits) covers how the five-hour and weekly windows work, what drains them, and how to stretch them before you upgrade.
- Annual Pro saves $40 a year against monthly. Annual billing is available for Pro and Team; Max is monthly only, and Enterprise is annual only.
- Upgrades apply immediately with unused time credited toward the new plan; downgrades take effect at the end of the billing period, and your chats, projects, and files stay with the account.
- Cancel at least 24 hours before renewal to avoid the next charge. Payments are generally non-refundable outside the consumer terms and local law, with a 14-day withdrawal window in the EEA and UK.
- If a feature is not in the table above, check the plan page. Anthropic's comparison table is long and changes without notice; this page is refreshed on a cadence, and the "Last verified" line at the top is the source of truth.

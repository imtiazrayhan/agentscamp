Mistral Vibe is the assistant that used to be called Le Chat. Mistral AI renamed it on May 28, 2026 and folded its chat assistant and its coding agent into one product: "Le Chat is now Vibe—one agent and one licence across work and code, with every conversation, setting, and plan carried over." Mistral's docs describe Vibe as its "unified agent for productivity and coding tasks, built for professional use and available across web, mobile, your code editor, and your terminal." The web app is still at chat.mistral.ai, with the same login.

It suits founders and small teams who want a European alternative to [ChatGPT](/tools/chatgpt) from Paris-based Mistral AI, and developers who would rather pay once for both a chat assistant and a terminal coding agent. If you are searching for Le Chat, this is the same product under its new name. The [best ChatGPT alternatives roundup](/guides/comparisons/best-chatgpt-alternatives-2026) compares it with the other general assistants.

## Highlights

- **Work mode.** The old Le Chat chat, now unified: Mistral's docs say that since September 22, 2026 "they're merged into a single experience," and a fast/think toggle "sets how deep Vibe goes." Enterprise organizations get a six-month migration window.
- **Connectors.** "Agentic work across an unbounded number of Connectors including Gmail, Outlook, Slack, Notion, Linear, GitHub, Atlassian, Google Drive, SharePoint, and Stripe." The Free plan lists 100+ connectors. Connectors and custom MCP connectors are marked beta on the pricing page as of November 2026. See [AI connectors](/glossary/ai-connectors) for what that means in practice.
- **Approvals you can see.** "Vibe asks for approval before sensitive actions, shows every tool call."
- **Skills and Projects.** Legacy Le Chat agents are gone: "Use Skills instead; invoke them with `@`." Deep Research is now the Deep Research Skill in Work.
- **Scheduled tasks.** Run a prompt "once or on a daily, weekly, monthly, or yearly cadence."
- **Documents and media.** Canvas, spreadsheets, slides, image generation, voice mode and a "Verified news" feature are on the plan table.
- **Code mode.** A CLI, a VS Code extension, Vibe Desktop for macOS and Windows, and remote sessions in a cloud sandbox. The Vibe CLI is open source under Apache-2.0 at github.com/mistralai/mistral-vibe.
- **Temporary Chat.** It "starts a conversation that isn't saved to your history or used to train our models."

## In an AI-assisted workflow

The two modes split the day cleanly. Work mode handles the recurring knowledge work; Code mode is a [coding agent](/glossary/coding-agent) in the same subscription. A made-up scheduled task for Acme's product lead:

```text
Every Monday at 09:00, read last week's messages in the #support Slack
channel and the open issues in the Linear "Bugs" project. List the five
problems customers raised most often, link the source for each, and say
which ones already have a Linear issue. Ask before creating anything.
```

Because Vibe asks for approval before sensitive actions and shows every tool call, you can let a task like this read widely and still decide what gets written back. On the developer side, Code mode competes with [Claude Code](/tools/claude-code) and the other terminal agents in the [Claude Code alternatives roundup](/guides/comparisons/best-claude-code-alternatives-2026). Mistral Large 4 can be selected in Vibe Code; Mistral calls it "our flagship 1-trillion-parameter, natively multimodal model," its model card lists 52 billion active parameters, and its weights were released on October 29, 2026 under the Mistral Ecosystem Open-Weight license, which Mistral calls "a modified MIT license" that requires a separate commercial licence for Model-as-a-Service businesses.

Mistral does not say which model runs Work mode. Its launch post says only that "Vibe runs on flagship Mistral models optimized for reasoning, agentic tasks, tool calls, and coding."

## Pricing

As of November 2026, Mistral's pricing page lists Free at $0, Pro at $14.99 per month excluding taxes, Student at $5.99 per month for verified students (normally $14.99), and Team at $24.99 per user per month, with Enterprise priced through sales. Free includes limited messages and web searches, limited coding sessions, basic image generation and editing, 100+ connectors and up to five scheduled tasks. Pro gives "full access to Vibe for all-day coding and long-running tasks," with up to 6x the Free messages, 5x the web searches, 40x the image generation and up to 15GB of libraries. Team adds up to 30GB of storage per user, domain name verification and data export; Enterprise adds custom models, audit logs, SAML SSO and white labelling. Code Interpreter in Work is available on paid plans only. The page shows monthly billing with no annual price.

## Good to know

Training is on by default for individuals. Mistral's help center says that on Free, Pro, Team and Student plans "input and output data are used by default to train our artificial intelligence models, unless you opt out," while "Enterprise customers are opted out of training by default." As of November 2026 the help center adds that the opt-out "does not apply to Labs and Public Preview models," whatever your plan, so check which model you have selected before pasting anything sensitive.

The rename is recent, so expect leftovers. Search results, browser bookmarks and older tutorials still say Le Chat, and features those tutorials describe, such as Le Chat agents, have been replaced by Skills. Vibe Desktop is listed for macOS and Windows only.

[DeepSeek](/tools/deepseek) is the useful contrast: a free app, MIT-licensed weights and a pay-as-you-go API, with personal data stored in China.

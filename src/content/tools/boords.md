Boords organizes storyboard planning around scripts and frames. Its Import Script feature uses AI to turn a supplied script or shot list into storyboard structure, dialogue or action descriptions, shot suggestions, and image prompts. Write with AI starts from a description, while a blank board supports manual planning. Optional character references can guide generated frames. [Boords' creation documentation](https://boords.com/docs/creating-storyboards) describes those approaches.

Frame notes can carry dialogue, action, camera, and timing. An animatic gives frames durations, with optional audio for a pacing preview; AI image generation is a separate step from shot planning. [Boords' concepts documentation](https://boords.com/docs/concepts) explains that structure.

## Trial it with an approved script

Our proposed evaluation starts with a short approved script, named action beats, and a list of required visual facts. Prepare shot briefs before asking for frame imagery so you can judge the proposal against something more specific than overall appearance. This is a review workflow, not a guarantee of character consistency or finished video.

In the fictional library-return explainer, a volunteer places a blue book in a slot, reads a receipt, and puts that receipt in a coat pocket. The book stays blue, and the receipt first appears after the slot action. The plan proposes three shots lasting three, four, and two seconds. These durations are a starting proposal for director review.

The [script-to-storyboard guide](/guides/design/ai-storyboard-from-script) keeps beat references and continuity requirements alongside the shot descriptions. If a frame shows a red book, the issue is a mismatch with the approved prop. A new refund scene is a script change, not merely a different composition.

## Review sequence and frames separately

Coverage asks whether every approved beat has a shot. Continuity asks whether action order and visual state remain coherent. A plan can cover all beat IDs while introducing the receipt too early. An image can satisfy one shot description while changing a prop between adjacent frames.

The [Storyboard Continuity Reviewer](/agents/design/storyboard-continuity-reviewer) can organize findings from an approved script and readable frames or supplied descriptions. It should say which evidence was available. Text saying “blue book” is insufficient to claim the actual image was visually inspected.

Use the [animatic](/glossary/animatic) stage to review the timing proposal as a sequence. In your trial, record the director's decisions about duration and action clarity alongside the continuity fixes. A correct duration total does not decide whether an action has enough time to be understood.

## Access and scope

As checked on October 7, 2026, Boords offers free and paid tiers, giving it a freemium directory classification. Verify the current offering directly. [Boords pricing](https://boords.com/pricing) is the reference.

Keep the script owner responsible for changing approved actions and the director responsible for production decisions. Preserve the source script and proposed repairs so the team can see why a shot changed. A successful trial ends with a reviewable sequence and explicit unresolved work, rather than assuming a set of generated images is already ready for production.
